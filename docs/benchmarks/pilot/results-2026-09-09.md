## Cost calculation

Using standard [Astra API prices](https://developers.openai.com/api/docs/models/gpt-6-astra)
checked on 9 September 2026: $10/M uncached input, $1/M cached input, $12.50/M
cache writes and $50/M output. Every clean run reports zero cache-write tokens.
The largest individual input was 20,515 tokens, below the long-context price
threshold. No fast-tier multiplier is assumed; recorded service tier is null.

`estimate = ((input - cached - writes) * 10 + cached * 1 + writes * 12.5 + output * 50) / 1,000,000`

Reasoning output is already within output totals and is not charged twice.
These are comparable API-equivalent estimates, **not actual subscription
charges or allowance measurements**. They exclude this supervising conversation,
benchmark preparation and any unreported provider-side work.

## Reproduction and next test

The [runner instructions](README.md) describe how to repeat the experiment.
Run order here was A, B, C; cache state was observed, not forced cold or equal.
Models were named aliases, not immutable backend snapshots. Global instructions
remain a shared influence, including a mention of the deployment skill. Those
limits matter for generalizing beyond this setup.

Next, use a task with meaningful repository exploration or independent subtasks
so delegation can earn its cost. Repeat conditions in varied order on multiple
tasks. Keep acceptance fixed; do not force B/C to delegate merely to produce a
desired comparison. A separate bounded delegation smoke test is needed to check
child telemetry and early wakeups before trusting multi-agent totals.
