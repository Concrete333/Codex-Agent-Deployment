# cattrs A/B/C results — 10 September 2026

All three saved implementations pass **16 feature checks and 265 frozen
regressions**. The skill-guided run used a cheap worker, but its larger
coordinator workload made it the most expensive condition. It also reached
the fixed process limit before returning a final completion message.

| Condition | Actual execution | External checks | Run outcome | Captured API-equivalent cost |
| --- | --- | --- | --- | ---: |
| A: no-skill solo | Astra High alone | 16/16 + 265/265 | Completed, 423.54 s | $1.436838 |
| B: unguided | Astra High + Astra High test worker | 16/16 + 265/265 | Completed, 356.68 s | $2.452440 |
| C: current skill | Astra High + Luna Max test worker | 16/16 + 265/265 | Timed out, 900.30 s | At least $3.021813 |

C costs at least **110.3% more than A** and **23.2% more than B**. Its code passes
the checks, but the bounded run remains partial. Time was not a quality metric;
the fifteen-minute safety cutoff nevertheless censors completion. More time
might have allowed a final report, but cannot erase cost already incurred.

The Luna worker cost **94.5% less** than B's Astra worker. But C's parent alone
cost more than B's entire team. Worker price was not the limiting factor.
C's parent made more model responses with a larger context: maximum request
input was 71,815, versus 50,612 for A and 52,382 for B. Larger carried context
and more model re-entries both contribute to accumulated input usage.

B omitted model, effort and fork overrides; its test worker used Astra High.
C explicitly selected Luna Max with `fork_turns: none`. Neither was required to
delegate. No other descendants were found in the recorded trees.

## Waiting and verification

C used **one native `collaboration.wait_agent` call**, with the configured
default timeout. It returned after approximately 180.724 seconds with
`timed_out: false`. No clock-sleep polling loop occurred. The previous waiting
problem is not the explanation for this result.

C's coordinator reported correcting missing Self annotations in the delegated
TypedDict/NamedTuple tests and addressing test-fixture failures before final
validation. It also wrote additional checks and reviewed generated-hook
customization. These are observed activities, not a measured attribution of
the entire parent-cost difference to worker repair. Implementation approaches
and test scope varied between runs too.

Agent-written case counts were not used as scores. A reported 194 new cases,
B 92 and C 54; all submissions faced the same external checks. Passing those
checks is a correctness floor, not proof of identical behavior on every input.

## Evaluation receipts

The initial read-only grader passed feature checks for A/B, but pytest's default
file-descriptor capture could not allocate temporary files. C timed out before
automatic grading. After all runs stopped, the same unchanged grader
ran read-only on each original checkout with `PYTEST_ADDOPTS=--capture=sys`.
Every run passed both gates, and `src/` hashes match before/after grading.
No submitted code, assertions or ACLs were changed; no model retry was started.

Original results and errors remain intact. Each trial has a separate
`sandbox-regrade.json`. The shared runner was updated after the experiment to
use in-memory pytest capture for future grading; participant prompts and the
grader's assertions were not changed during this experiment.

## Accounting and limits

Unique per-response usage sums reconcile with final per-thread cumulative
counters for all five agents. Copied parent history in a fork is not counted
again as child usage: records are selected by owning thread ID. Cache writes
are zero and service tier is null. Interrupted in-flight usage may be missing
from C, so its captured cost is a lower bound.

The standard API-equivalent rate basis remains Astra $10/M input, $1/M cached,
$50/M output; Luna $0.20/$0.02/$1.20. Sources:
[Astra](https://developers.openai.com/api/docs/models/gpt-6-astra) and
[Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna).
Reasoning output is already included, not added twice. These are not subscription
charges or allowance measurements. Preparation, supervision and offline grading
are outside the trial totals.

Runs started B, A, C, roughly ten seconds apart, and overlapped in independent
checkouts. Cache state, service scheduling and sampling were not controlled;
shared resource contention can affect elapsed time and timeout risk. One public
feature on one repository is development feedback, not a general model ranking
or causal estimate of the skill's effect.

## What to retain

The skill selected an appropriately inexpensive worker and avoided a busy-wait
loop. That was insufficient to reduce total cost. Future changes should be
tested for how much coordinator implementation, checking and correction they
actually remove. Test authoring should not be assumed mechanical merely because
its output is test code. This run does not justify a universal ban on test
delegation or a blanket model switch. No operational skill edits were made.
