Preparation and acceptance together are about 82% of the delegated total.

poll MiMo. The resumed CLI's final usage event is cumulative: it was reconciled
against per-response telemetry, not added to preparation a second time.

Sol solo took 664.864 seconds. Delegated stages took 160.231 seconds for
preparation, 1,038.72 for MiMo and 396.524 for acceptance, plus host setup/checks.
Speed was not the optimization target.

## Worker result and accuracy

MiMo used `kilo/xiaomi/mimo-v2.6-pro`, variant `thinking`, through Kilo 7.7.6.
Its receipt is **failed**, despite process exit 0: it reached the 30-step cap
and returned no valid JSON handoff. Ownership was released, termination was
confirmed and the lock was absent. This is not a successful autonomous Kilo
delivery. Unlike earlier no-artifact attempts, it produced all six adapters,
a shared helper and tests that Sol could inspect and repair.

After isolating a worktree newline-conversion issue described below, the
unrepaired worker submission passed all 244 frozen cases. Sol independently
found that a raw quote in an unquoted CSV field was accepted by Python's
`csv.reader(strict=True)`. It added validation and one regression. The candidate
and accepted artifact differ only in `_shared.py` and `test_adapters.py`.

The same post-hoc input was run on all three artifacts:

```text
id,date,amount,currency,memo
a,2024-02-29,1,USD,x"y
```

- Solo Sol: rejected with `ValueError`.
- MiMo before repair: accepted.
- Delegated final result: rejected with `ValueError`.

This supports that specific review correction and exposes a gap in the frozen
suite. It is not an additional held-out result or proof of complete correctness.
No model saw the private grader's output for repair.

## Harness limitations and recovery

1. The initial harness stopped after Sol completed because its JSONL parser split
   a Unicode separator inside a JSON string. The saved output was recovered;
   no paid stage was repeated. See [recovery record](recovery-2026-09-21.md).
2. The Kilo Git worktree converted protected-file line endings. Its original
   byte-hash grade failed before behavior checks. All protected contents match
   after CRLF-to-LF normalization, and Git reports only permitted worker changes.
   A separate regrade copied the **unaltered worker-owned files** onto pristine
   protected inputs, matching the host's actual integration path; all 244 cases
   passed. Original worktree, failed grade and evidence remain intact. Future
   fixtures should pin checkout line endings before either arm starts.
3. The resumed Sol final response retained the planning contract's JSON shape.
   Acceptance was independently graded rather than inferred from that shape.
   A future run should explicitly select an acceptance response schema instead
   of carrying the planning schema into that stage.

The task, model settings and prompts were unchanged for recovery. Nevertheless,
call this a **recovered comparison**, not an uninterrupted harness success.
Routing was forced, the fixture had been used previously, order was solo first,
and CLI/tool environments differ. More tests in one submission are not evidence
that it is more accurate. No larger-budget retry or new model run was launched.

## Takeaway

For this bounded implementation batch, Sol solo was cheaper through acceptance.
MiMo displaced some Codex work but not enough to offset assignment and acceptance
cost plus its own bill. Retaining substantive acceptance was useful. Do not
weaken it or raise the worker limit based on this single result.
